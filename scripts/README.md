# أدوات الصيانة

- check.mjs: فحص تلقائي لبناء JavaScript وتناسق ملفات واجهة العمل ونسخة PWA. يعمل دون حزم إضافية أو اتصال بـ Supabase.
- npm run verify: فحص المشروع ثم تشغيل الاختبارات.

تضاف هنا أدوات المطور فقط؛ لا تضع أسراراً أو أدوات تعدّل الإنتاج تلقائياً. تبقى scripts خارج ترتيب تحميل واجهة workspace.html.
