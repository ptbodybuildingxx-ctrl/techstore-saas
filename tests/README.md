# اختبارات TechStore

المتطلبات: Node.js 24 كما هو محدد في package.json.

| الأمر | الغرض |
|---|---|
| npm run check | فحص بناء JavaScript تلقائياً في الجذر وmodules وscripts وtests، وفحص ملفات workspace.html وتوافق الكاش ورقم الإصدار |
| npm test | تشغيل ملفات tests/*.test.mjs |
| npm run verify | الأمران السابقان معاً، وهو أمر CI |

تضاف اختبارات المكونات الجديدة في tests/ باسم واضح ينتهي بـ .test.mjs. استخدم fixtures مؤقتة، ومحاكاة API أو SQLite المحلية بحسب طبيعة الاختبار، ولا تستدعِ إنتاج Supabase من CI.

## قبل اعتماد إصدار
فحوص JavaScript وPWA ليست بديلاً عن اختبار SQL على بيئة معزولة، واختبار صلاحيات حقيقية، والتزامن، والمصادقة الثنائية على الهاتف، والجرد الفعلي أو النسخ الاحتياطي والاستعادة. سجّل نتائج هذه الاختبارات مستقلة في [ملاحظات الإصدار](../docs/releases/README.md).
