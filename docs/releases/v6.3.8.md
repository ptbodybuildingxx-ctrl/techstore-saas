# TechStore 6.3.8 — Stability candidate (not production-certified)

## Changes
- Added 24 supporting foreign-key indexes (including two previously only partially covered); performance advisor now shows no WARN and no unindexed foreign-key findings. Newly created indexes have not yet accumulated usage statistics; 29 unused-index INFO notices are not a reason to delete them.
- Split the broad admin grants policy into insert/update/delete policies, leaving the existing read scope and restrictive live-session policy unchanged.
- Standalone debt and installment creation/payment now use the existing durable request-confirmation mechanism (IndexedDB) and server-side operation-status RPC. No new navigation or data migration.
- A regression test covers an uncertain network response, reload-like reconstruction, blocking changed input and retrying with the original ID.

## Verified
- Supabase rollback tests passed for the new policy structure and indexes, debt payment replay, and server confirmation scope.
- Integrated rollback scenario passed: supplier purchase + payment, linked installment invoice + receipt + cancellation, loyalty accrual/reversal, standalone debt + payment, branch transfer + sale, payroll accrual, central stock quantity and all 15 reconciliation checks. This is a sequential database test, not a multi-device or full end-to-end test.
- New JavaScript regression test passed in an isolated JavaScript harness using repository source and simulated persistence/network. The complete Node 24 suite and GitHub Actions remain unverified.
- No permanent test customers, invoices or financial entries were retained.
