# Published high-resolution media
Private originals stay private; only an explicitly permitted original with the matching referenced thumbnail in the active published design can be resolved by the trusted worker. Revocation denies subsequent requests but cannot recall prior copies. Worker checks JPEG frame dimensions and scan-marker structure, rejecting header-only, truncated and trailing-byte images, but does not fully decode pixels; no-store, fixed origin, bounded response. Do not enable publicMediaEnabled until deploying the intentional public endpoint, testing actual upload/download and enforcing rate limits. No worker deployed in this stage; fallback thumbnails remain active.
